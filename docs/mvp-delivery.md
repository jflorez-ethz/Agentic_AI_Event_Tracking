# MVP delivery record

**Delivery status.** The video CLI, stored-result queries and three-agent workflow run together offline on archived model decisions and original footage. The current provider configuration and newly integrated path await a fresh authorized live run. The delivered evaluation makes no estimate of recognition accuracy on new sites.

The runtime still checks the cited observation, ordered frames, source and differing pixels. Investigation's previously simplified provider grammar is preserved. |
| Perception geometry to relation validator | Two marks could have the same center and different radii and pass checks requiring distinguishable positions. | Such marks cannot establish distinct positions for the nearby judgment, distinguishable endpoints, or same-pair continuity. Approach is still evaluated against the spacing and uncertainty evidence. Autonomous pixel geometry is a model assessment. |
| Valid relation to timeline and answers | The graph could preserve a validated relation on an insufficient individual Event. A timeline filtered on the host verdict could drop it from time-based retrieval. | Each accepted relation appears once at its own interval with its own citations. Direct relation questions and event-relative anchors use the accepted typed claim. Partial individual verdicts retain their status. Text about people walking together cannot create a supported joining or separation claim. |
| Stored run to follow-up question | The live CLI could answer questions during execution. Later local queries required an experiment-specific loader. | The same CLI reads a trusted saved workflow analysis, checks the supplied video's identity, and answers without a new inference request. |
| Physical transport to run record | Live outputs advertised media request ceilings without logging physical media sends on the shared SDK client. | A media budget enforces and records sends alongside role attempts, HTTP status and actual total. A transient role retry counts toward the physical ceiling. |

The normal input is a local video. The CLI uses a model decision at each reasoning node. Video Perception receives source pixels and Verification receives source-linked observations. Reporting selects its lead and emphasis, then the renderer produces the user-facing report. The evidence ledger, full source intervals and incomplete checks remain available even when the report is partial. [Architecture and execution commands](../README.md)

## Operational limits

The model can abstain, choose four individual tasks, fail to request the remaining observations, or generate visual geometry that fails the uncertainty threshold. The recorded 10–13 s divergence proposal remained insufficient. Distinguishable paths, increasing spacing and persistent person identity have different evidence requirements. The autonomous perception interface cannot supply independently established links across an occlusion. Retrieval supports a bounded set of lexical queries. A no-match answer or a scan gap does not establish absence. Three initial windows also limit how much of a long input the MVP examines.

The remaining external test is one authorized video-first run with the new Verification schema. Check the actual provider completion, role/inspection traces, omitted observations, original pixels behind each proposed transition, relation outcomes, report and saved-answer round trip. A live pair of unrelated traces would not establish calibrated accuracy or prove that extra planning metadata improves decisions. The reproducible command, payload and cap for the single run are in the [delivery guide](../README.md).

## Reproduction notes

Software schema and graph regressions use local SDK transports or archived responses. The ordinary CLI integration test exercises source ingestion, an open relational assignment, targeted frame inspection, a subsequent unresolved verdict and Reporting. It does not measure Gemini's likelihood of choosing that assignment. The separate recorded-response regression reproduces the live eight-frame approach response and its selected proposal ID.

The broader regression run uncovered two compatibility problems in older experimental harnesses. The adaptive inspection pilot now accepts the graph's optional task argument and continues to limit itself to the individual candidate pilot. The historical temporal-hypothesis comparison pins the recorded 1,024-token role ceiling and LOW thinking rather than inheriting current MVP role settings. Neither harness runs during a production investigation.

The installed versions used for delivery were Python 3.12, google-genai 3.6.1, LangGraph 1.2.14, Pydantic 2.14.4 and pytest 9.2.0. The saved-run CLI reproduced both delivered answers. A second clean-output replay and visual review reproduced the analysis JSON, Markdown report, both review manifests and both review sheets byte-for-byte.

Git history from the user's checkout was unavailable in the mounted workspace. The delivery branch `mvp/end-to-end-delivery` is based on a local source/documentation snapshot. The bundle preserves its base and delivery commit. To bring the delivery commit into another checkout, fetch the branch from the bundle and cherry-pick the tip onto the intended base after inspecting the diff. Existing original media and historical archives remain local prerequisites for reproduction.
